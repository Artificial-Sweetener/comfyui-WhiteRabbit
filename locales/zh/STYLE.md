# WhiteRabbit 简体中文术语与风格

- 以简洁、清晰的中文说明功能；保留 RIFE、FPS、SSIM、MSE、L1、GPU、CUDA、VRAM、CSV、fp16 与 bf16 等技术标识。
- `frame` 使用“帧”，`frame interpolation` 使用“插帧”，`resample` 使用“重采样”，`frame rate` 使用“帧率”。
- `scale factor` 使用“缩放系数”，`ensemble` 使用“双向集成”，`seam` 使用“接缝”，`loop` 使用“循环”。
- 输入和输出标签用短语；说明和提示用完整、自然的句子。不要翻译节点 ID、输入 ID、输出位置或选项原始值。
- 文案应说明用户可观察到的行为、限制和性能取舍；避免逐词直译英文句法。
